### 2. Core Functionality

- [ ] Implement `get_hot_100()` in `R/get_hot_100.R`:
    - Arguments: `date` (string, e.g., "2026-11-10"), `range` (e.g., "1-10")
    - Use `httr::GET()` with headers:
        - `x-rapidapi-host: billboard-api2.p.rapidapi.com`
        - `x-rapidapi-key: Sys.getenv("RAPIDAPI_KEY", "<TEST KEY>")`
    - Parse JSON using `jsonlite::fromJSON()`
    - Return as data.frame or list of named data.frames
    - Include TODO comment for rate-limiting (e.g., suggest delays or caching)

- [ ] Optional file export function:
    - `export_hot_100(date, range, csv_path = NULL, rds_path = NULL)`
    - Saves result as `.csv` and/or `.rds` with timestamp in filename
