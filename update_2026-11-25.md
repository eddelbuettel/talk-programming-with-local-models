
### Inkling-2-mini with 16gb RAM

Using ['mainline'](https://huggingface.co/unsloth/Inkling-2-Mini-GGUF/tree/main/Mainline_Support)
builds (via [the hint here](https://github.com/ollama/ollama/issues/19888#issuecomment-7149782884))
we can run in standard ollama (rather than the version using patched llama.cpp that unsloth has).

Using a Modelfile with somewhat reduced context such as this

```make
FROM ./Inkling-2-Mini-UD-IQ3_XXS.gguf
PARAMETER num_ctx 16384
PARAMETER temperature 1.0
PARAMETER top_p 1.0
PARAMETER top_k 0
PARAMETER min_p 0.0
```

deployed via `ollama create inkling2-mainline-iq3-xxs -f Modelfile` and used along with ollama
configuration extended to

```make
[Service]
Environment="OLLAMA_HOST=0.0.0.0"
Environment="OLLAMA_KEEP_ALIVE=-1"
Environment="OLLAMA_CONTEXT_LENGTH=32768"
Environment="OLLAMA_FLASH_ATTENTION=1"
Environment="OLLAMA_KV_CACHE_TYPE=q8_0"
Environment="OLLAMA_MAX_LOADED_MODELS=1"
```

permits this to run in the 16gb setting we have:

```sh
$ ollama ps
NAME                                ID              SIZE     PROCESSOR    CONTEXT    RUNNER      UNTIL   
inkling2-mainline-iq3-xxs:latest    a21fa7efa6ea    13 GB    100% GPU     16384      llamacpp    Forever    
$
```
